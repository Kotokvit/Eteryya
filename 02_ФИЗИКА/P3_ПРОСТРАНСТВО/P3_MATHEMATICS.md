## 1. ОПРЕДЕЛЕНИЕ

### 1.1. Формальное

```
P³ = (R⁴ \ {0}) / ~
(X, Y, Z, W) ~ (λX, λY, λZ, λW),  λ ∈ R, λ ≠ 0
```

Точка P³ = класс эквивалентности `[X : Y : Z : W]` = **прямая через 0 в R⁴**.

### 1.2. Факторизация через сферу

```
P³ = S³ / (x ~ −x)
```

Единичная 3-сфера S³ ⊂ R⁴ с антиподальным отождествлением. Каждая пара противоположных точек склеена в одну.

### 1.3. Размерность

```
dim_R P³ = 3
```

Локально — R³. Глобально — нет (см. §3).

---

## 2. ОДНОРОДНЫЕ КООРДИНАТЫ

Координаты `[X : Y : Z : W]` определены с точностью до общего множителя λ ≠ 0.

| Область | Канонический вид | Аффинная карта |
|---------|-----------------|----------------|
| W ≠ 0 | `[x : y : z : 1]` где x=X/W, y=Y/W, z=Z/W | U_W (основная) |
| X ≠ 0 | `[1 : y : z : w]` где y=Y/X, z=Z/X, w=W/X | U_X |
| Y ≠ 0 | `[x : 1 : z : w]` где x=X/Y, z=Z/Y, w=W/Y | U_Y |
| Z ≠ 0 | `[x : y : 1 : w]` где x=X/Z, y=Y/Z, w=W/Z | U_Z |

---

## 3. АТЛАС ИЗ ЧЕТЫРЁХ АФФИННЫХ КАРТ

### 3.1. Карты

```
U_W = { [X:Y:Z:W] | W ≠ 0 }  — основная карта (наблюдатель)
U_X = { [X:Y:Z:W] | X ≠ 0 }  — восток
U_Y = { [X:Y:Z:W] | Y ≠ 0 }  — север
U_Z = { [X:Y:Z:W] | Z ≠ 0 }  — вверх/вниз
```

### 3.2. Переходы — дробно-линейные (Мёбиус)

Переход U_W → U_X (когда W→0, точка уходит «на бесконечность» в U_W, но входит в U_X):

```
(x, y, z) ∈ U_W  →  (1/x, y/x, z/x) ∈ U_X
```

Эти переходы **нелинейны**. Нельзя «продолжить по непрерывности» — нужно переключать карту.

### 3.3. Переключение при W = 0

Когда узел P³ достигает W = 0 (антипод), система переключается на другую карту в зависимости от азимута подхода α:

| α | Направление | Новая карта |
|---|-------------|-------------|
| ≈ 0 | Восток | U_X |
| ≈ π/2 | Север | U_Y |
| ≈ π | Запад | U_X (обратный знак) |
| ≈ 3π/2 | Юг | U_Y (обратный знак) |

## 4. ТОПОЛОГИЯ

### 4.1. Компактность

P³ **компактно**. Доказательство: P³ = π(S³), S³ компактно, π непрерывна → образ компакта компактен.

Следствие: **нельзя «убежать на бесконечность»**. Любой объект локализуем.

### 4.2. Ориентируемость

```
P³ — ОРИЕНТИРУЕМО
deg(антиподальная инволюция) = (−1)^(n+1) = (−1)^4 = +1
```

Можно глобально определить «правый» и «левый» виток. В P² этого нет (лента Мёбиуса).

### 4.3. Фундаментальная группа

```
π₁(P³) = ℤ/2ℤ
```

**Ключевой факт для ОС Дракона:**
- Один оборот (2π) — **нетривиальная петля**, класс 1 ∈ ℤ/2ℤ. Не стягивается.
- Два оборота (4π) — **тривиальная петля**, класс 0 ∈ ℤ/2ℤ. Стягивается.

Голономия:
```
Hol_γ = exp(iπ) = −1  (один обход)
Hol_γ² = exp(2iπ) = +1 (двойной обход)
```

Физический смысл: ОС Дракона **автоматически детектирует** объекты, совершившие нечётное число оборотов — они помечены как «чужеродные».

### 4.4. Гомологии

```
H₀(P³) = ℤ         (связно)
H₁(P³) = ℤ/2ℤ      (кручение — = π₁ абелианизованное)
H₂(P³) = 0
H₃(P³) = ℤ         (фундаментальный класс — ориентируемое)
```

### 4.5. Эйлерова характеристика

```
χ(P³) = 0
```

### 4.6. Связь с SO(3)

```
P³ ≅ SO(3)
```

Через кватернионы: S³ → SO(3) двулистное накрытие, ядро {±1}. Поэтому SO(3) ≅ S³/{±1} ≅ P³.

Для кватерниона q(θ) = cos(θ/2) + k·sin(θ/2):
- q(2π) = −1 (не единица! нетривиальный обход)
- q(4π) = +1 (единица, тривиальный обход)

## 5. МЕТРИКА ФУБИНИ–ШТУДИ

### 5.1. Определение

```
d_FS(v₁, v₂) = arccos( |⟨v₁, v₂⟩| / (‖v₁‖ · ‖v₂‖) )  ∈ [0, π/2]
```

Это **угол между направляющими** в R⁴. Максимальное расстояние = π/2 (антипод).

### 5.2. SO(3)-конъюгация через кватернионы

```
d_SO3 = 2 · arccos( |⟨q₁, q₂⟩| )
```

## 7. Ω И χ — ПОРЯДОК И ХАОС

### 7.1. Определение через гиперплоскости

```
Ω:  W = 1  (гиперплоскость Порядка)
χ:  Z = 0  (гиперплоскость Хаоса)
```

Угол θ(Ω, χ) между ними **зависит от положения** на планете.

### 7.2. Ключевые зоны

| θ | Зона | Свойства |
|---|------|----------|
| 0° | Чистый Ω | Платиновый вакуум, полная структура |
| 45° | Граница | φ-поле максимально |
| 80° | Круг Костей | 12 χ-Левиафанов, 18.7 Гц×100 |
| 85° | Порог L_∅ | Начало нуль-жидкости |
| 90° | Ω⊥χ | Максимальный хаос, ρ_∅(90°) = 0.007596 |

## 8. НУЛЬ-ЖИДКОСТЬ L_∅

### 8.1. Определение

```
L_∅ = { p ∈ P³ | θ(Ω, χ)(p) > 85° }
```

Фрустрированная критическая точка φ-среды, где Ω⊥χ с углом > 85°.

### 8.2. Проективная плотность

```
ρ_∅(θ) = sin²(θ − 85°) · H(θ − 85°)
```

H — функция Хевисайда. При θ < 85°: ρ_∅ = 0. При θ = 90°: ρ_∅ = sin²(5°) ≈ 0.007596.

### 8.3. Проективная оптика

```
n_∅ = i · n_Ω · √(ε_χ / ε_Ω)
```

Мнимый показатель преломления → **эванесцентное** (затухающее) поле. Свет не распространяется, а экспоненциально затухает. Глубина проникновения:

```
δ_opt(φ) = 25.4 мкм
```

### 8.4. Z/2Z голономия в L_∅

```
Hol_γ = exp(iπ) = −1  (один обход через L_∅)
Hol_γ² = +1            (двойной обход — возврат)
```

## 9. ОС ДРАКОНА И P³

### 9.1. Почему Дракон выбрал P³, а не R³

| Критерий | R³ | P³ | Выбор |
|----------|-----|-----|-------|
| Начало координат | Выделено | Нет | P³ |
| Бесконечность | Не часть пространства | Включена как гиперплоскость | P³ |
| Параллакс | Измерим | Структурно нулевой | P³ |
| Защита | Программная | Топологическая (Z/2Z) | P³ |
| Дикие вложения | Норма | Рассасываются/регистрируются | P³ |
| Край мира | Бесконечность | Нет (компактно) | P³ |
| Привилегированный наблюдатель | Есть | Нет | P³ |

**Дракон — инженер, не бог.** P³ — осознанный архитектурный выбор, не мистика.

### 9.2. Антивирусы Кроны (три уровня)

1. **Топологический:** Z/2Z-класс нетривиален → объект «застревает» на петле
2. **Ориентационный:** ориентация не согласована → аннигиляция при бифокальной сингулярности
3. **Компактностный:** размер превышает компактный объём P³ → потеря локализации

### 9.3. Почему Нокс обошла P³-защиту

Нокс — из **другой метрики** (не P³, не CP³). Её Z/2Z-класс **не определён** в P³.

**Решение:** экстремальная энтропийная компрессия — инкапсуляция чужеродной геометрии в биологический контейнер (Соболь) с легитимной P³-сигнатурой.

Антивирусы видят **Соболя** (корректная топология, ориентация, размер). Внутри — архив Нокс, но он **не экспортирован в P³-метрику**. Данные, не геометрия.

**Нокс — свидетель предела P³.** Её существование доказывает, что за P³ есть другие геометрии.

## 11. КРУГ КОСТЕЙ В P³

12 χ-Левиафанов расположены на окружности d=120м с θ≈80°.

В P³-координатах (R = 5838.4 км):

```
Левиафан_k: [sin(θ_k)·cos(φ_k), sin(θ_k)·sin(φ_k), 0, cos(θ_k)]
φ_k = 2πk/12,  k = 0..11
θ_k ≈ 80° = 80·π/180 рад
```

Каждый Левиафан — точка в P³. Круг Костей — 12-вершинный правильный многоугольник на проективной прямой в P³.

## 12. СИММЕТРИИ

### 12.1. Группа проективных преобразований

```
PGL(4, R) = GL(4, R) / R*
```

Действует **транзитивно**: любую точку можно перевести в любую. Нет привилегированных точек.

### 12.2. Золотой угол протоки

```
λ = π × 10⁻¹⁰ рад
```

Оптимум между λ→0 (T→∞) и λ→π (стазис). В P³: «случайность» невозможна по определению. P³ вводит **проекционный детерминизм**:

```
p(x | W, λ) = δ(x − x₀(W, λ))
```

«Судьба» = P³-детерминизм, наблюдаемый через незнание λ.
