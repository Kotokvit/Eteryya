Пусть Φ(dI, dΣ) — параметр порядка, удовлетворяющий: ### Требования **R1. Репараметризационная инвариантность** Поскольку нет внешнего времени, выбор параметра s произволен. При замене s → f(s): dI → dI·f’, dΣ → dΣ·f’. Требование: Φ(dI·f’, dΣ·f’) = Φ(dI, dΣ) Физический смысл: время — внутреннее свойство траектории, не артефакт описания. **R2. Аддитивность по информации** Если наблюдатель A обрабатывает dI_A бит, а B — dI_B бит при том же dΣ: Φ(dI_A + dI_B, dΣ) = Φ(dI_A, dΣ) + Φ(dI_B, dΣ) Это значит: Φ линейна по dI. Φ(α·dI, dΣ) = α·Φ(dI, dΣ) Физический смысл: время аддитивно по информационной пропускной способности. Двойная информация = двойное время. Каждый бит равен. **R3. Обратная пропорциональность по структуре** Если структурное изменение удваивается при фиксированной информации: Φ(dI, β·dΣ) = Φ(dI, dΣ) / β Физический смысл: больше структуры на бит = меньше времени на бит. Термодинамическая цена. **R4. Корректные пределы** - Стазис: dI→0, dΣ→0 → T = неопределено (разрешается пределом) - Транзит: dI>0, dΣ→0 → T→+∞ (внутренняя вечность) - Смерть: dI→0, dΣ>0 → T→0 (время остановилось) - Норма: dI>0, dΣ>0 → T>0 (конечно, положительно) **R5. Непрерывность** Φ непрерывна для dI>0, dΣ>0. ### Теорема Если Φ(dI, dΣ) удовлетворяет R1–R5, то: **Φ(dI, dΣ) = c · dI/dΣ** для единственной константы c > 0. ### Доказательство **Шаг 1:** R1 → Φ однородна степени 0. R1: Φ(t·dI, t·dΣ) = Φ(dI, dΣ) для всех t > 0. Функция, однородная степени 0, зависит только от отношения: Φ(dI, dΣ) = f(dI/dΣ) = f(r), где r = dI/dΣ. **Шаг 2:** R2 → f линейна. R2: Φ(α·dI, dΣ) = α·Φ(dI, dΣ). Подставляя Φ = f(r), где r = dI/dΣ: Левая часть: Φ(α·dI, dΣ) = f(α·dI/dΣ) = f(α·r) Правая часть: α·Φ(dI, dΣ) = α·f(r) Следовательно: f(α·r) = α·f(r) для всех α > 0, r > 0. Полагая r = 1: f(α) = α·f(1) = c·α, где c = f(1). Следовательно: f(r) = c·r. **Шаг 3:** R3 удовлетворяется автоматически. Φ(dI, β·dΣ) = f(dI/(β·dΣ)) = f(r/β) = c·(r/β) = (c·r)/β = Φ(dI, dΣ)/β. ✓ **Шаг 4:** Пределы R4. - Стазис: r = dI/dΣ → const (если dI и dΣ → 0 одинаково), T → c·const. ✓ - Транзит: r → +∞, f(∞) = c·∞ = +∞. ✓ - Смерть: r = 0, f(0) = c·0 = 0. ✓ - Норма: r > 0, f(r) = c·r > 0 при c > 0. ✓ **Шаг 5:** Непрерывность R5. f(r) = c·r непрерывна для всех r. ✓ **Шаг 6:** c > 0. Из R4(d): T > 0 в нормальном режиме → c·r > 0 при r > 0 → c > 0. ✓ **QED.** *** ## ОБОСНОВАНИЕ R2 (ключевая аксиома) R2 (аддитивность по информации) — сильнейшее требование. Она убивает все альтернативы: (dI/dΣ)², √(dI/dΣ), ln(1+dI/dΣ) и бесконечно много других. ### Три аргумента в пользу R2 **(a) Термодинамический:** Каждый бит стоит kT·ln(2) (Ландауэр). N бит = N·kT·ln(2). Субъективный опыт пропорционален полной стоимости → линеен по N. T = N·(kT·ln(2))/dΣ = c·dI/dΣ. **(b) Феноменологический:** Ольга: 0.3с (dI = 1.0×) Алексей: 0.6с (dI = 2.0×) Вэнс: 1.0с (dI = 3.3×) Связь линейная: T ∝ dI. Если бы R2 нарушалась (T ∝ dI²), лаг Алексея был бы 0.3×4 = 1.2с, а не 0.6с. **(c) Информационно-теоретический:** Биты — атомарные единицы. N-й бит не отличается от (N-1)-го. Если бы время было нелинейно по информации, это означало бы, что N-й бит качественно отличается — но все биты идентичны по определению. ### Статус R2 R2 — **фундаментальный принцип теории**, не доказанный факт. В физике существуют системы с нелинейным откликом (насыщение, фазовые переходы). Но R2 — разумная аксиома, подтверждаемая тремя независимыми аргументами. *** ## ЧТО ИСКЛЮЧАЕТСЯ | Кандидат | Почему не работает | |—|—| | I·Σ | Не проходит R1 (не инвариантна).
