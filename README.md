## Использование с POLER Engine

Репозиторий является тестовым корпусом для [poler-engine](https://github.com/poler-engine-org/poler-engine) — 
AI-native поискового движка. После установки движка:

```bash
# Поиск по консолидированному корпусу
poler-engine ~/Eteryya -q "Алексей" --format ai-json
# Ожидание: ~10 696 хитов (см. INSTALL.md §6)


# Поиск только по архиву
poler-engine ~/Eteryya/99_АРХИВ_ИСХОДНИКИ -q "запрос"


# Семантический поиск (нужна модель bge-m3.pqw)
poler-engine ~/Eteryya --semantic dense --model models/bge-m3.pqw -q "Печать Инверсии"
```

## Ключевые элементы мира

### География

- **5 континентов:** Главный (~46 млн км²), Западный, Южный, Восточный архипелаг, Северный ледовый

- **5 регионов:** Проклятые Княжества, Империя Золотого Солнца, Леса Востока, Западные Хребты, Абресс

- **Океан Этерии** покрывает 83-89% поверхности


### Физика

- **P³** — пространство описывается как проективное многообразие (не евклидово R³)

- **Анизотропия времени** K = 9/7 (18 земных = 14 этерийских)

- **Нулевой параллакс** — фундаментальное свойство топологии

- **Ω/χ дуальность** — Порядок vs Хаос, основа всей физики


### Персонажи (18)

Алексей Коганенко (Патч-01), Рэй Вэнс (Наследник-00), Марта, Ольга, Райдо Тэнма...


### Фракции (11)

Империя Золотого Солнца, Северная Конфедерация, Эльфийская Симбиократия, Инквесторат И-3...
