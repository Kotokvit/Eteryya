## 1. ПОЧЕМУ КЛАССИЧЕСКИЙ WEB SEARCH / RAG ДЛЯ AI — ЭТО ТУПИК

Современные поисковики и парсеры (типа `curl`, `requests`, `read_url_content`) ломаются на 85% реального интернета:
1. **SPA и динамический JS:** Страница пустая, пока не исполнится React/Vue/Angular бандл. Обычный парсер видит `<div id="root"></div>` вместо статьи или документации.
2. **Shadow DOM, Canvas, iFrames:** Скрытые компоненты интерфейсов и документаций не видны в статическом HTML.
3. **Cloudflare / Cloud-Defenses / Captcha:** Блокируют любые запросы без TLS-фингерпринта реального браузера.
4. **Бесконечная лента и WebSockets:** Данные подтягиваются по сокетам потоком.

## 2. АРХИТЕКТУРА ИНТЕГРАЦИИ: `poler-engine` + CHROMIUM CDP

Вместо того чтобы парсить слепой HTML, движок подключается напрямую к запущенному или встроенному инстансу Chromium по **Chrome DevTools Protocol (CDP)** через WebSocket на Rust (библиотека `chromiumoxide` или нативный WebSocket-клиент):

```
                       [ URL / Web Search Query ]
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │   Chromium Headless / Live Browser Session (CDP)       │
       │   ├── Page.navigate + Network.enable                   │
       │   ├── Execution: Выполнение JS + рендеринг DOM         │
       │   ├── Runtime.evaluate: Извлечение чистого Render Tree  │
       │   └── Network Interceptor: Перехват JSON-ответов API    │
       └────────────────────────────┬───────────────────────────┘
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │   Zero-Copy Ingestion Streamer                         │
       │   (Очистка от DOM-мусора, рекламы, CSS и скриптов)     │
       └────────────────────────────┬───────────────────────────┘
                                    │
                                    ▼
       ┌────────────────────────────────────────────────────────┐
       │   POLER Pipeline Core (Rust)                           │
       │   ├── Расчет ε и R на лету прямо из веб-страницы       │
       │   ├── AST / Markdown Scene Anchor                      │
       │   └── Встраивание в общий Entity Graph с репозиторием │
       └────────────────────────────────────────────────────────┘
```

## 3. ЧТО ЭТО ДАЕТ AI-АГЕНТУ:

1. **Парсинг без ограничений (Bypass SPA & Shadow DOM):**
   * Браузер полностью отрисовывает страницу со всеми скриптами, и AI получает чистый семантический текст того, что реально видит пользователь.
2. **Перехват скрытого API (Network Sniffing):**
   * Часто документация или база данных на сайте грузится через непубличный внутренний `fetch('/api/v2/docs')`. Браузер перехватывает сырой JSON-ответ еще до того, как он превратился в разметку!
3. **Прямое связывание Веба с Локальным Репозиторием (Cross-Universe Graph):**
   * Найденная документация по Rust/C++ из интернета **на лету становится узлом в локальном графе сущностей** и связывается с функциями в твоем коде через K-Hop:
     `[Моя функция alloc_buffer] -> [зависит от] -> [Документация man mmap из Chromium]`.
4. **Сквозной Резонанс ($\varepsilon$ и $R$):**
   * Из 20 открытых страниц документации движок оставляет только те 2 абзаца, где информационная плотность $\varepsilon$ максимальна относительно твоего текущего бага в коде.
