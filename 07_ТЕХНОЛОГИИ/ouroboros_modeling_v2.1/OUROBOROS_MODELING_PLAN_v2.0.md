### 3. Модуль «Метрика P³» (02_p3_metric.py)

* Радиальная параметризация (от опорного узла-шлюза) — **точна по построению**:
  невязка с большим кругом 4.2·10⁻¹⁶ (машинный эпсилон).
* Зоны поля W(s) = cos(s/2R): протечка 0.01% → **165 км**; 1% → **1653 км**;
  29.3% (экватор карты, W = 0.7071) → **9172.8 км**; антипод W→0 → **18345.4 км**.
* Переключение карт атласа по max|координата| — продемонстрировано на дрейфе
  к антиподу (U_W → U_X).
* **Четность Z/2Z** численно: петля 360° → SU(2)-фаза −q (класс 1, карантин);
  петля 720° → +q (класс 0, верифицирован). π₁(RP³) = Z/2Z.
* Точность: δW = 10⁻⁹ → δs = 11.7 мм (центр зоны).

**Проектное правило (новое):** межузловая d_FS-геодезика несет надбавку кручения
от −15% до +146% против поверхностной дуги → маршрутизация только радиальная
от опорных узлов; межузловые связи — только при d_FS ниже порога транзита.

## 📗 ТОМ 2. СФЕРЫ И ПЛАНЕТАРНАЯ ИНТЕГРАЦИЯ (05_spheres_engine.py — ВЫПОЛНЕНО)

### A. Планетарный резонатор: вывод 18.7 Гц

Отсев: изгибная мода оболочки 2.5·10⁻⁶ Гц ✗; обходная акустика 2.29c ✗;
резонатор Гельмгольца (устье 55× поверхности) ✗. **Принята мода n=2
ЭМ-полости: f = (c/2πR)·√6·v_f = 8.171 × 2.449 × 0.934 = 18.70 Гц.**
Легирование подняло v_f с 0.78 (землеподобные потери) до 0.934. Часы
бесплатны: 2.0 МВт диссипации = 2.2·10⁻¹¹ от реактора. n=1 запрещен
(альфа-полоса 8-13 Гц); 18.7 Гц у резонанса глазных яблок = «Гул Бездны».

### B. Литосферная интеграция

* Флюс: закон кубии, v = 0.52 м/с, Re = 661 (ламинарно), 100-м горизонт
  за 3.2 мин, сеть 10⁷ км = **5.1 млрд т** (канон ✓).
* **Глубина меридианов 20-80 м = скин-слой такта**: δ(σ_eff = 3…30 См/м) =
  21…67 м. Самосбор: поле → ток в трещине → разогрев → приток флюса → рост σ.
* География: поле ~ P₂(cosθ) → пучности у полюсов/экватора, кольцо тени ±54.7°.

### C. Таблица 22 Сфер (двухканальная модель)

* Несущий канал: P = ε₀²·σ_e, ε₀ = 0.866 φВ (калибровка: шахтер σ 7.8 ↔ 5.85 Вт).
* Канал Ландауэра: Q = ΔI·E_bit (лестница ×4.442 из Тома 1).
* Группы: S0-S5 io_bind/freq_tune; S6 v_alloc (Форма); S7 m_lock (Предел,
  σ ≥ 9.0); S8-S14 w_transform; S15-S21 core_interrupt/flux_pump; S22 kernel_exec.
* Лестница σ воспроизводит якоря: S0 = 1.5 (фоновый), S7 = 9.0, S22 = 10.0.

### D. Каскадный закон формообразования (S1 → S6)

Тепло (пятно 17 см, контура нет) → Давление (сжатие ×184) → Поток (**опасная
фаза**: сброс в локус 15 см³) → Вектор → Связи → Форма = контракт
(dE_j/dt = 0 ∀j). Боевой темп S3: 106 Дж → 7.1 Дж/см³ > некроз 4.7 Дж/см³.
Информационное усиление S1→S6 = ×1729.

### E. Энергетическая архитектура

Низшие Сферы — тело оператора (1-7 Вт). S15-S21 — прямой отбор из реактора:
1 кВт → 7.7 МВт (шаг ×4.442); оператор платит только управление.
Убийство Формой = аннулирование контракта цели → самосброс цели.

### F. Физика оператора: три режима отказа

1. **Шинный** (σ < σ_req): джоулев разогрев сутками = CNED-износ
   (норма σ6.5 + S7 → 9.4 сут; фон σ1.5 → 0.2 сут).
2. **Бюджетный** (Q > Q_max): острый всплеск (S22 = 90% бюджета за вызов).
3. **Указательный (Нокс)**: адрес вне P³ → аллокация 46.8 МГц → переполнение
   1.4 мс → сброс 18.95 МДж / 23.7 МВт / 1300 °C / 0.8 с (кросс-чек 89%).
