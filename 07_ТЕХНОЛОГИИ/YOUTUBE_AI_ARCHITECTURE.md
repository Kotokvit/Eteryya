# 📺 АРХИТЕКТУРА ИИ YOUTUBE: ПОЧЕМУ ОН РАБОТАЕТ БЕЗ ТРАДИЦИОННЫХ GPU

---

## 1. СЕКРЕТ ЖЕЛЕЗА: VCU (ARGOS) И TPU ВМЕСТО ОБЫЧНЫХ GPU

На YouTube каждую минуту загружается более **500 часов видео** (миллиарды часов просмотров в день). Если бы Google обрабатывал всё это на стандартных потребительских или серверных GPU (типа NVIDIA A100/H100), дата-центры сгорели бы от перегрева и счетов за электричество.

Google создал **специализированные заказные ASIC-чипы**:

```
 ┌────────────────────────────────────────────────────────┐
 │ 1. VCU (Video Coding Unit / Чип "Argos")               │
 │    • Аппаратный кремниевый ASIC для транскодирования   │
 │    • 10x энергоэффективнее любых GPU                   │
 │    • Обрабатывает видеопотоки в реальном времени       │
 └──────────────────────────┬─────────────────────────────┘
                            │
                            ▼
 ┌────────────────────────────────────────────────────────┐
 │ 2. Google TPU (Tensor Processing Unit v4 / v5p)        │
 │    • Матричные умножители (bfloat16, int8)             │
 │    • Рекомендательные модели Two-Tower DNN             │
 │    • Инференс за 5–10 миллисекунд                      │
 └──────────────────────────┬─────────────────────────────┘
                            │
                            ▼
 ┌────────────────────────────────────────────────────────┐
 │ 3. CPU-Кластеры (Zero-Copy In-Memory Caching)          │
 │    • Быстрая фильтрация миллиардов видео               │
 └────────────────────────────────────────────────────────┘
```

## 2. АРХИТЕКТУРА РЕКОМЕНДАЦИЙ YOUTUBE (КАК ЭТО РАБОТАЕТ)

Система рекомендаций разбита на 2 строгие фазы (чтобы не нагружать нейросети):

```
 [ 1 000 000 000+ видео в каталоге ]
                 │
                 ▼
  ┌──────────────────────────────┐
  │  Фаза 1: Candidate Generation│ ──► Быстрый отбор по эмбеддингам
  │  (Двухбашенная Two-Tower)    │     Отсекает 99.999% видео
  └──────────────┬───────────────┘
                 │ (Остаются сотни кандидатов)
                 ▼
  ┌──────────────────────────────┐
  │  Фаза 2: Deep Ranking        │ ──► Тяжелая модель ранжирования
  │  (Нейросеть с контекстом)    │     (время суток, глубина досмотра)
  └──────────────┬───────────────┘
                 │
                 ▼
        [ Топ-20 в ленте пользователя ]
```

## 3. ЧТО ОТКРЫТО В OPEN SOURCE (ИСХОДНИКИ И СТАТЬИ)

Google полностью открыл фундаментальные библиотеки и статьи, на которых построен YouTube AI:

### А. Официальные научные статьи Google:
1. **«Deep Neural Networks for YouTube Recommendations» (Covington et al.):**
   * Статья: `https://research.google/pubs/deep-neural-networks-for-youtube-recommendations/`
   * Главный документ, описывающий разделение на Candidate Generation и Ranking.
2. **«VCU: Google's Custom Video (Argos) ASIC» (ASPLOS 2021):**
   * Описание аппаратного чипа Argos для транскодирования миллиардов видео.

---

### Б. Открытый исходный код (GitHub):

1. **`TensorFlow Recommenders (TFRS)` — официальный движок рекомендаций:**
   * Репозиторий: `https://github.com/tensorflow/recommenders`
   * Содержит готовые реализации **Two-Tower моделей** (башня пользователя + башня видео), ScaNN для быстрого поиска и ранжирования.
2. **`ScaNN` (Scalable Nearest Neighbors — сверхбыстрый векторный поиск Google):**
   * Репозиторий: `https://github.com/google-research/google-research/tree/master/scann`
   * На чистом C++ с поддержкой SIMD (AVX-512) — именно он находит видео за миллисекунды без GPU.
3. **`MediaPipe` (Компьютерное зрение и обработка видео на CPU):**
   * Репозиторий: `https://github.com/google/mediapipe`
   * Инференс нейросетей по видеокадрам (распознавание лиц, жестов, сегментация) прямо на CPU телефонов и серверов.
