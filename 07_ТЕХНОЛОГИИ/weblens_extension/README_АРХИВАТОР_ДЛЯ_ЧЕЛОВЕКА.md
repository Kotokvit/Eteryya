# 📥 POLER WebLens — Архиватор для человека

Расширение Chrome, которое превращает архивацию в POLER в **банальное
«копировать → вставить»** и пару кликов мышью. Без JSON, без консоли,
без консольных команд — вся магия (`poler_chunk` через MCP-шлюз) спрятана
внутри, для ИИ всё как прежде на высоте, для человека — тоже.

## Установка (3 шага, один раз)

1. Скачайте папку `weblens_extension` (или весь репозиторий) на диск.
2. Откройте в Chrome страницу `chrome://extensions` → включите переключатель
   **«Режим разработчика»** (справа вверху).
3. Нажмите **«Загрузить распакованное расширение»** → укажите папку
   `weblens_extension`. Готово — иконка 📥 появится на панели.

> Ежедневно нужен только запущенный `poler-engine` с MCP-шлюзом
> (`http://127.0.0.1:8765/mcp`). Адрес и Bearer-токен расширение берёт из
> своего `config.json` — при желании переопределяются в окне архиватора,
> вкладка **⚙️ Шлюз**.

## Пять способов архивировать — выбирайте любой

| Способ | Как | Куда удобно |
|---|---|---|
| **Правый клик** | Выделите текст на любой странице → правая кнопка → **«📥 POLER — Архиватор» → «Выделенное — в POLER»** | Быстро сохранить фрагмент, не отходя от чтения |
| **Копипаст** | Скопируйте что угодно **в любом приложении** → клик по иконке 📥 → **Ctrl+V** → кнопка **«Архивировать в POLER»** (или кнопка «📋 Из буфера») | Заметки из Word, почты, PDF — со всех программ |
| **Alt+P** | Нажмите **Alt+P** на вкладке с ИИ-чатом (Grok, ChatGPT, Claude, Gemini, DeepSeek, NotebookLM) | Захватить всю ветку диалога целиком, с авто-скроллом истории |
| **DropZone** | Правый клик → «📂 DropZone» (или ссылка в окне архиватора) → **перетащите файлы мышью** → «Отправить всё» | Пакет файлов: тексты, код, заметки, скриншоты |
| **Из адресной строки** | Наберите `poler` + пробел в адресной строке → текст заметки → **Enter** | Мысл (draft), не отрывая рук от клавиатуры |

Есть и правый клик по **ссылке** («Ссылку — в POLER») и по **картинке**
(«Изображение — в POLER»), и «**Всю страницу — в POLER**» — текст открытой
страницы целиком.

## Что видно человеку после отправки

- **Уведомление Windows/ОС**: «✅ «Заголовок» → POLER · 4.2 КБ» — для правого
  клика, Alt+P и адресной строки.
- **Зелёный статус в окне** архиватора: размер, число частей, время ответа.
- **Бейдж на иконке**: `✓` — успех, `!` — ошибка, `×N` — пакет нарезан на N частей.
- **🕘 История** (вкладка в окне архиватора): последние 40 отправок; кнопка
  «📋 Скопировать» возвращает текст назад в буфер — архив работает в обе стороны.

## Если не работает

| Симптом | Причина и лечение |
|---|---|
| «шлюз: офлайн» под заголовком | Не запущен poler-engine с MCP-шлюзом. Запустите движок, затем вкладка ⚙️ → «🧪 Проверить шлюз» |
| «poler_chunk недоступен» | Шлюз жив, но инструмент не виден — обновите poler-engine (слои MCP с прямым приёмом `content` из памяти) |
| HTTP 401/403 | Bearer-токен не совпадает — вкладка ⚙️ Шлюз → вставьте токен из config.json движка → 💾 Сохранить |
| Alt+P пишет «инъекция невозможна» | Страница системная (chrome://, магазин расширений) — там браузер запрещает скрипты; используйте копипаст |
| Картинка не вставилась в popup | Скриншоты и картинки — в DropZone (popup принимает только текст) |

## Что происходит с данными

Текст уходит одним POST-запросом на ваш локальный шлюз
`http://127.0.0.1:8765/mcp` (JSON-RPC `tools/call` → `poler_chunk`
`{source, title, url, content}`). Большие пакеты автоматически режутся на
части по границам абзацев (по умолчанию 120 000 символов, настраивается).
Ничего не уходит в интернет, кроме вашего движка на этом же компьютере.
