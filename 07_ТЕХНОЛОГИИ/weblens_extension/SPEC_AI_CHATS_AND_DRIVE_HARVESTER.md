# 🚀 ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ ДЛЯ GLM / AI-РАЗРАБОТЧИКА): WEBLENS UNIVERSAL HARVESTER

**Проект:** Расширение `WebLens` для браузеров (MV3 / Chromium)  
**Шлюз приёма:** `POLER Engine Terminal Gateway` (`http://127.0.0.1:8765/mcp`)  
**Цель:** Превратить WebLens в **Универсальный Комбайн (Harvester)** для пакетного сбора, парсинга и прямой стриминговой выгрузки данных из всех ИИ-чатов и облачных дисков в единый защищённый архив `.poler`.

## 2. СПИСОК ПЛАТФОРМ ДЛЯ ПОДДЕРЖКИ (ОБЯЗАТЕЛЬНО)

### А. ИИ-Чаты (Автоматический сбор всей ветки диалога)
1. **Grok (x.com/i/grok & x.com/grok):**
   * Парсинг сообщений пользователя и Grok (включая режим Fun / Regular / Think).
   * Сохранение рассуждений (Thinking blocks) и вложенных сниппетов.
2. **ChatGPT (chatgpt.com / chat.openai.com):**
   * Захват всей цепочки сообщений (User / Assistant / System).
   * Парсинг блоков кода, формул LaTeX/KaTeX, метаданных canvas и artifacts.
3. **Google Gemini (gemini.google.com):**
   * Снятие скрытых черновиков (Drafts), сгенерированного кода, цитат поиска.
4. **Anthropic Claude (claude.ai):**
   * Захват диалогов, блоков Artifacts (React, SVG, Python, Markdown), разметки XML.
5. **DeepSeek (chat.deepseek.com):**
   * Захват веток рассуждений `think` (DeepSeek-R1 CoT) + финальных ответов.
6. **Google NotebookLM (notebooklm.google.com):**
   * Автоматический экспорт всех заметок (Studio Notes), чатов и цитат источников.

---

### Б. Облачные Хранилища (Пакетный сбор без ручного кликания)
1. **Google Drive (drive.google.com):**
   * **Пакетный режим:** При открытии папки на Диске — обход списка файлов (Google Docs, Sheets, PDF, TXT) и отправка содержимого пакетом через Google Export API / iframe fetch.
   * **Одиночный режим:** Перехват открытого документа Google Docs без искажения форматирования.
2. **Microsoft OneDrive / Dropbox / MEGA:**
   * Снятие публичных/авторизованных папок и текстовых превью.

## 3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ К КОДУ (CONTENT.JS & PANEL.JS)

1. **Кнопка «📥 Захватить весь чат / папку в POLER»:**
   * Внедряется плавающей иконкой в интерфейс поддерживаемых сайтов.
   * По нажатию: автоматически скроллит страницу вверх (lazy load), собирает все сообщения DOM от начала до конца, преобразует в чистый Markdown с тегами метаданных (Дата, Модель, Заголовок, Платформа).
2. **Стриминг в MCP Gateway:**
   * Отправка через метод `poler_chunk` / `notes_add` / `stream_ingest` на `http://127.0.0.1:8765/mcp`.
   * Заголовок `Authorization: Bearer <token>` из `config.json`.
3. **Авто-очистка от мусора:**
   * Исключение кнопок «Copy», «Regenerate», аватаров, рекламных баннеров и UI-хлама.
   * Сохранение чистой математики, кода и смыслового текста.
