## 1. МАСШТАБ ВИЗИИ: ЕДИНЫЙ ШЛЮЗ КО ВСЕМ ХРАНИЛИЩАМ МИРА

Цель — сделать `poler-engine` универсальным шлюзом (Hub), который **нативно и без сторонних костылей** подключается, индексирует и связывает в единый $K$-Hop граф знания из любых систем контроля версий кода и сверхбольших массивов данных (Data Lake / ML Models).

```

 │                      POLER-ENGINE UNIFIED REPO HUB                     │
 └───────────────────────────────────┬────────────────────────────────────┘
                                     │
         ┌───────────────────────────┼───────────────────────────┐
         ▼                           ▼                           ▼
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│ 1. КЛАССИЧЕСКИЙ  │        │ 2. БОЛЬШИЕ ДАННЫЕ│        │ 3. ML & AI HUB   │

│ • Git (libgit2)  │        │ • Git LFS        │        │ • Hugging Face   │
```

## 2. ПОДДЕРЖИВАЕМЫЕ СИСТЕМЫ И ИХ НАЗНАЧЕНИЕ

### А. Кодовые системы (Source Code VCS):
1. **Локальный Git & `git2-rs` / `gix` (Pure Rust Git):**
   * Чтение истории коммитов, веток, diff-режим на уровне деревьев объектов (`tree/blob`) без спавна медленной утилиты `git`.
2. **GitHub & GitLab REST/GraphQL API:**
   * Прямая индексация Issues, Pull Requests, Discussions, Release notes в `web-index.db`.
3. **Lit (Rust-native Version Control):**
   * Сверхбыстрая нативная работа с современным Rust-контролем версий.
4. **HugeSCM (от Ant Group):**
   * Поддержка сверхгигантских монорепозиториев (миллионы файлов) без выкачивания всего дерева на диск.

---

### Б. Большие датасеты и веса нейросетей (Data & Model Hubs):
1. **Git LFS (Large File Storage):**
   * Парсинг метаданных и указателей (Pointers) больших файлов без забивания локального диска терабайтами блобов.
2. **DVC (Data Version Control):**
   * Индексация пайплайнов данных (`dvc.yaml`), хэшей датасетов и версий дата-озер.
3. **Oxen.ai (Сверхбыстрый VCS для терабайтных датасетов):**
   * Нативное чтение индексов Oxen для работы со структурированными терабайтными таблицами.
4. **Hugging Face Hub (HF API):**
   * Поиск по карточкам моделей (Model Cards), датасетам (Datasets) и коду репозиториев прямо через CLI.

---

## 3. ЧТО ЭТО ДАЕТ В ЕДИНОМ ПОИСКЕ:

Один запрос в терминале:
```bash
poler-engine -q "трансформер внимания" --all-sources
```
одновременно выдаст:
* **Строку кода** из локального репозитория Rust/C++;
* **Модель и датасет** из Hugging Face Hub;
* **Историю коммита** из GitHub/GitLab;
* **Заметку** из NotebookLM;
* **Терабайтный срез** из Oxen/DVC!
