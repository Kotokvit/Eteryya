## Быстрый старт

```bash
# Зависимости: python3, numpy, scipy, mpmath, reportlab, pypdf
cd scripts
python3 00_axioms_verify.py     # верификация канона
python3 01_filter_cascade.py    # частотный фильтр
python3 02_p3_metric.py         # метрика P³
python3 03_bio_bus.py           # тепловая шина
python3 04_simulator.py         # интегрированный симулятор
python3 05_spheres_engine.py    # движок Сфер (Том 2)
python3 06_races_biology.py     # биологическое железо (Том 3)
python3 06_build_pdf_vol1.py    # пересборка Тома 1 (нужен cover.pdf)
python3 07_build_pdf_vol2.py    # пересборка Тома 2 (нужен cover2.pdf)
```

Топология зависимостей: скрипт с меньшим номером никогда не читает выходы
скрипта с большим номером. Симулятор (04) читает все JSON. Генератор
отчета (05) только читает.
