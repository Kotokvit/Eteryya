Приоритет: слово автора > кодекс > этот слой.

## 1. Правило

Иногда нужно **φ**, иногда нужно **ф**. Критерий — смысл:

**φ (греческая буква, читается «фи»)** — когда речь о **поле, чистом фредерите, радиации**:
- явления и проявления поля (φ-поле, φ-фон, φ-излучение);
- природные проявления чистого фредерита (φ-жилы, φ-кристаллы);
- физические свойства поля (φ-частота, φ-энергия, φ-плотность, φ-проводимость);
- устройства и инфраструктура, названные по функции поля (φ-телескопы, φ-каналы, φ-сеть).

**ф (русская буква)** — когда что-то из фредерита **уже сделано** (продукты, вещества):
- готовый металл, спирт, конденсат, руда, шлам, дистиллят, смола и так далее.

**Сплав** — только «ф-сплав» (русская «ф»). Написаний «φ-сплав» и «фи-сплав» не существует.

**«фи-» словом (кириллицей)** — запрещено. Всегда символ: φ- (поле) или ф- (продукт).

## 2. Канонические таблицы

### 2.1. φ- (поле / чистый фредерит / радиация / функция поля)

φ-поле, φ-поля, φ-фон, φ-шум, φ-излучение, φ-радиация, φ-частота, φ-энергия, φ-поток,
φ-доля, φ-подпитка, φ-резонанс, φ-плотность, φ-проводимость, φ-ионизация, φ-свечение,
φ-градиент, φ-баланс, φ-уровни, φ-ответ, φ-голос, φ-частицы, φ-подписи, φ-связь,
φ-сеть, φ-каналы, φ-узлы, φ-магистраль, φ-телескопы, φ-сенсорика, φ-резонаторы,
φ-томография, φ-фильтры, φ-дренаж, φ-жилы, φ-жильный, φ-кристаллы, φ-кристаллизованные,
φ-структуры, φ-панели, φ-каркас, φ-армирование, φ-симбионты, φ-проспекторы, φ-сгустки,
φ-супплементы, φ-хладагент, φ-сплайс.

### 2.2. ф- (продукты и вещества из фредерита)

ф-сплав (базовая валюта Этерии; «Живой Ф-сплав»), ф-металл, ф-конденсат, ф-руда,
ф-шлам, ф-дистиллят, ф-смола, ф-спирт, ф-заражение, ф-структуры материальные —
по контексту: если структура вещественная (изделие) — ф-, если полевая — φ-.

Именованные сплавы с суффиксом: **Аргенто-Ф, Платино-Ф** (заглавная Ф как часть имени).

## 3. Примеры (проверка правила на живом тексте)

| Фраза | Верно | Почему |
|---|---|---|
| «гранит-α, пропитанный **ф-смолой**» | ф | смола — сделанный продукт |
| «чемодан чёрного **ф-сплава**» | ф | сплав — сделанный продукт |
| «пластина, легированная **ф-сплавом**» | ф | сплав — продукт |
| «октэдр, удерживаемый **φ-полем**» | φ | поле |
| «под толщей смога и **ф-конденсата**» | ф | конденсат — вещество |
| «монополия на добычу **ф-руды**» | ф | руда — добытый продукт |
| «**φ-жилы**» в породе | φ | жилы — чистый фредерит в природе |
| «огарки **φ-фона**» | φ | фон — явление поля |
| «ф-сплав — это проводник **φ-поля**» | оба | сплав сделан, поле — явление |

## 4. Примечания

1. «фи-е-десять» в файле МАРШРУТЫ — не термин, а расшифровка произношения формулы
   «φ=е10»; сохранено как есть.
2. Записи «Φ-» и «Ф-» с заглавной нормализуются по тем же правилам; «Живой Ф-сплав»
   как именованная сущность сохраняет заглавную Ф.
3. В POLER-технических документах (07_ТЕХНОЛОГИИ) греческая φ выступает математическим
   символом (χ→φ, khi-phi) — это другая область, правило фредеритовой орфографии там
   не применяется.
4. История правила: пролог Тома 2 («Теорема распада») содержал разнобой ф-/φ-/фи-
   (унаследованный от черновых планов и канон-документов). Правило автора сняло
   разночтение: смысловая граница — «явление поля» против «сделанный продукт».
